First time here?

Nobody has a password yet. On the server that runs GRC-pal, create the first admin:

grcpal create-admin you@example.com --name "Your Name"

Rebuilding from a backup?

Copy the backup file and your recovery kit to the server, then restore instead of creating an admin. Everyone signs in with their existing accounts afterwards.

grcpal backup restore FILE.grcbak --kit recovery-kit.json
