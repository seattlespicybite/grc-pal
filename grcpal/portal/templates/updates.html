Updates on Azure

The monthly update job checks for a new release. Patch releases install automatically; feature and major releases wait for approval. Each new version first runs beside the current one without traffic, is checked, and only then takes over. The previous version stays ready for a one-click rollback.

Details and the rollback command: docs/deploy-azure.md, "Updates".

{% else %}

Manual installation

This copy of GRC-pal was not installed with the VM installer, so updates are manual: take a backup, install the new version, start it. Migrations run on start and refuse data they cannot read.

For automatic, checked updates with rollback, use the VM installer (docs/deploy-vm.md).
