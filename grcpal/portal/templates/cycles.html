Change the current cycle

The first cycle starts automatically on the day GRC-pal is first opened. Set it to your real audit period here, for example your SOC 2 Type 2 observation window. Past-due warnings on the calendar start from this date. The change is written to the audit log.

Start the next cycle

Starting a cycle closes {{ cycle.name }}. With carry-forward, every request that was not cancelled is copied to the new cycle with the same people and instructions, and each new request links to last cycle's evidence and comments so people can see what they did before.
